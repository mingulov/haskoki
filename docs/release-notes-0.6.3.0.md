# Haskoki 0.6.3.0 release notes

Shipped 2026-11-28.

## Refactor — behavior-identical module splits

- Every large Haskell module is split into small single-concern
  family modules behind a re-export shell. Public APIs and
  export lists are byte-identical; no behavior changes.
- Lib splits (shell lines before → after, family modules):
  Driver 4259 → 1103 (31), KeyManagement 4548 → 351 (9),
  SQLite 3119 → 99 (12), Async 2358 → 229 (9),
  Detached 1860 → 120 (8), Object 1711 → 63 (11),
  Storage 2238 → 141 (17). Import cycles broken by moving
  shared types down (Job/JobState, table-close types,
  TerminalState, execStateOf, knownMaterialEncodings);
  the backend contract moves out of TokenIdentity into its
  own Storage/Contract module.
- Test splits: KeyManagementSpec 10316 → 220 (12),
  StoreSpec 6297 → 219 (9), OpenSSLSpec 5718 → 109 (12),
  grouped by suite structure with shared fixtures sunk to
  per-split Fixtures. The 36 hand-built `testSession`
  copies share one parameterized helper in
  `tests/support/TestSession.hs` (slot 7 everywhere except
  SessionCancelSpec's slot 0, kept through the parameter).
- Gates: new module-size ratchet in `check-exposure.py`
  (1200-line lib / 4000-line test budgets, 7 pinned
  exceptions for skips and follow-ups); `check-test-wiring.py`
  resolves dotted helper modules; the sealed-callwork,
  history-codes and findings-ledger pins ride along to the
  new homes.

## Verification

- Golden sweep passing (67,808 rows, zero EXN rows); all 8
  test suites passing with identical test counts
  (model 1811, engine 468, storage 550, core 381, …);
  zero-warning builds (every module verified with exact
  `Compiling` lines); every moved span verified
  byte-identical in both directions by script.
- `.so` export parity vs the 0.6.2 baseline build
  (`cabal build all --flags=+usdt`, same toolchain):
  C ABI exports identical (`C_GetFunctionList`,
  `C_GetInterface`, `C_GetInterfaceList`); all 152
  `haskoki_*` native symbols identical as a set; every
  remaining `nm` delta is a GHC-internal rename
  (module-mangled names, info-table/closure suffixes,
  string uniques) — zero diffs outside that class.
- Compatibility matrix regenerated byte-identical except
  the version cells (script-verified pairing).
- Full static gate block passing, including the new size
  ratchet and the dotted-module wiring controls.
